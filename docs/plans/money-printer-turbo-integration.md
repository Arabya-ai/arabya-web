# دمج MoneyPrinterTurbo جنبًا إلى جنب مع عربية ستوديو

تاريخ الفحص: 2026-08-18  
المستودع المرجعي: https://github.com/harry0703/MoneyPrinterTurbo (MIT)  
الحالة: **مساران متوازيان غير هجينين** — استوديو الآيات تحت `/studio` يبقى كما هو؛ مولّد الفيديو بالذكاء تحت `/studio/ai`.

---

## 1) المقارنة بعد فحص المشروعين

### عربية ستوديو (هذا المستودع)

| البعد | الواقع |
|--------|--------|
| المسار | `/studio` · `/studio/dashboard` · `/studio/projects` · `/studio/editor/[id]` · `/create` الخفيف |
| التقنية | Next.js 15 داخل `src/ayat-studio/**` — تصدير MP4 في المتصفح (WebCodecs) |
| المحتوى | آيات المصحف + قرّاء EveryAyah + خلفيات Pexels/Pixabay |
| التشغيل | نفس عملية `next start` على Contabo — بلا Python/ffmpeg على السيرفر |
| الهوية | RTL، توكنات `--brand` / `.ayat-studio`، حساب Google واحد |
| الحراسة | جلسة مطلوبة على الـ shell؛ خطة مجانية بعلامة عربية |

### MoneyPrinterTurbo (المشروع المضاف)

| البعد | الواقع |
|--------|--------|
| الواجهات | WebUI (Streamlit :8501) + FastAPI (`/api/v1` :8080) + CLI |
| التقنية | Python 3.11، ffmpeg/MoviePy، LLM، TTS، Whisper اختياري |
| المحتوى | موضوع/كلمات → سكربت بالذكاء → لقطات مخزون → صوت → ترجمة → BGM → فيديو HD |
| التشغيل | عملية طويلة على السيرفر (دقائق)، مفاتيح LLM/TTS/Pexels |
| المقاسات | 9:16 و 16:9 (و1:1 في المخطط) |
| الترخيص | MIT — يُذكر Harry / MoneyPrinterTurbo في NOTICE |

### ماذا لا يغطّيه كل طرف

- استوديو الآيات **لا** يولّد سكربتًا من موضوع عام، ولا يركّب فيديو على السيرفر، ولا يدعم Edge TTS لغير التلاوة.
- MoneyPrinterTurbo **لا** يعرف المصحف ولا طبقات الدراسة ولا قرّاء القرآن، وWebUI ليست بهوية عربية.

الخلاصة: منتجان لنفس «صناعة فيديو قصير»، بجوهريْن مختلفين. الدمج الهجين (خلط النماذج في محرّر الآيات) يكسر الاثنين. الدمج غير الهجين: صفحات مستقلة + محرّك Python منفصل + جسر API مصادق عليه.

---

## 2) مبدأ الدمج (غير هجين)

1. **لا تُعدَّل** ملفات محرّر الآيات (`Editor.tsx` / تصدير WebCodecs / مخزن المشاريع المحلي) إلا بروابط تنقّل.
2. **يُنسَخ المشروع كاملًا** تحت `services/money-printer-turbo/` كخدمة شقيقة (مثل عامل المزامنة: standalone، بلا `file:` إلى جذر Next).
3. **صفحات مستقلة** تحت `/studio/ai` داخل صدفة الاستوديو الحالية (نفس الحساب والشريط الجانبي).
4. **جسر Next** `/api/studio/ai/*` يوكّل إلى FastAPI فقط بعد تسجيل الدخول — المتصفح لا يتحدث إلى :8080 مباشرة.
5. إن توقف المحرّك: الواجهة تعمل وتعرض حالة «المحرك غير مشغّل» مع خطوات المالك — بدون كسر `/studio` أو المصحف.

```
الزائر ─► /studio          استوديو الآيات (موجود)
         /studio/ai        مولّد الذكاء (جديد)
              │
              ▼
         /api/studio/ai/*  (جلسة Google + حد طلبات)
              │
              ▼
         MONEYPRINTER_API_URL  →  FastAPI :8080
              │
              ▼
         services/money-printer-turbo (Python + ffmpeg)
```

---

## 3) الصفحات المستقلة

| المسار | الدور |
|--------|--------|
| `/studio/ai` | هبوط عربي للمولّد + حالة المحرك |
| `/studio/ai/create` | نموذج كامل: موضوع، سكربت، كلمات بحث، مقاس، صوت، ترجمة، BGM |
| `/studio/ai/tasks` | قائمة المهام |
| `/studio/ai/tasks/[id]` | تقدّم + تشغيل/تنزيل الفيديو |

روابط جانبية فقط من: شريط الاستوديو، لوحة الاستوديو، هبوط `/studio`، حسابي، `/create`.

---

## 4) واجهة FastAPI المستخدمة (بدون إعادة كتابة بايثون)

من `app/controllers/v1`:

- `POST /api/v1/videos` · `POST /api/v1/scripts` · `POST /api/v1/terms`
- `GET/DELETE /api/v1/tasks` · `GET /api/v1/tasks/{id}`
- `GET/POST /api/v1/musics` · `GET/POST /api/v1/video_materials`
- ملفات المهام عبر `/tasks/...` تُعاد كتابتها إلى `/api/studio/ai/files/...`

---

## 5) التشغيل بجانب عربية

- محليًا: `docker compose -f docker-compose.mpt.yml up` ثم `MONEYPRINTER_API_URL=http://127.0.0.1:8080` مع `npm run dev`.
- Contabo: عملية ثانية (Docker أو venv) على 8080؛ Nginx يبقي 3000 لعربية فقط.
- المصحف و`/studio` لا يحتاجان Python.

---

## 6) ما لن يُنفَّذ في هذا الدمج

- لا iframe لـ Streamlit داخل الموقع (مظهر أجنبي + مفاتيح مكشوفة).
- لا خلط سكربت الذكاء داخل محرّر الآيات.
- لا نشر تلقائي إلى TikTok/YouTube من واجهة عربية (يبقى في إعداد MPT إن فعّله المالك محليًا).
- لا تشغيل ffmpeg داخل عملية Next (Vercel/Turbopack لا يصلحان لذلك).
