## مبادئ

1. الإبقاء على شعار `BrandLockup` والرمز `/brand/arabya-mark-ui.webp`
2. هوية تيل فقط (بدون نيلي في كلمة «عربية»)
3. عمق بصري غني (ظلال ملوّنة، سطوح، حبوب خفيفة) — ليس سطحاً فقيراً

5. لغوي = محرر ورقي هادئ + مساحة عمل بارزة
6. المحاور/التذييل = نفس اللغة التحريرية مع محتوى كل صفحة
