# لغوي السحابي — رؤية الركيزة داخل عربية

**الحالة**: مسودة منتج · 2026-08-20  
**الاسم**: لغوي  
**الدور**: الركيزة اللغوية التقنية داخل منصة عربية — تدقيق، تعلّم، سحابة، ووسائط لاحقًا.

## 1) المبدأ

لغوي ليس «غلاف ChatGPT». هو محرك عربي هجين:

1. **أوفلاين دائمًا**: قواعد + تعلّم جماعي + (لاحقًا) نماذج مفتوحة على Contabo.  
2. **سحابة Auto**: تبديل تلقائي بين مفاتيح/مزودين/نماذج مثل Cursor Auto.  
3. **خصوصية**: مفتاح كل مستخدم له وحده؛ مفاتيح المشروع للحصة المجانية فقط.  
4. **تعلّم**: قبول/رفض الجمهور يغذّي ذاكرة المشروع وGit.

## 2) وضع Auto (مُنفَّذ الآن)

الترتيب عند طلب صياغة / ترجمة / تشكيل ذكي:

```text
مفاتيح المستخدم (الافتراضي أولًا)
        ↓ فشل؟
مفاتيح مشروع عربية (Groq → Google → OpenRouter → OpenAI → Anthropic)
        ↓ فشل الجميع؟
رسالة واضحة + بقاء التدقيق المحلي
```

الإعداد على الخادم: `LUGHAWI_PROJECT_AI_POOL` أو `LUGHAWI_*_API_KEY`.

## 3) تجربة المستخدم المتكاملة (أفق المنتج)

### الآن (نص)
- تدقيق إملاء/نحو/ترقيم مع شرح القاعدة  
- قبول/رفض → تعلّم  
- إعادة صياغة فصيحة · ترجمة · تشكيل · تفقيط  
- حماية النص القرآني وربط المصحف/الدراسة  

### قريبًا
- لوحة «ثقة الاقتراح» ونسب التعلّم  
- قاموس مؤسسي خاص (كلمات لا تُصحَّح)  
- إضافة متصفح + API لمحرري المواقع  
- تدقيق ملفات DOCX/PDF  

### لاحقًا (صوت وصورة)
- تدقيق نص مستخرج من صوت (تفريغ → لغوي → نص مصحح)  
- تدقيق ترجمة الشاشة / عناوين الفيديو  
- استوديو عربية: سكربت فصيح قبل التسجيل  
- كشف لهجة → تحويل إلى فصحى (اختياري)  

### تميّز عربية
- ربط كلمة المصحف بطبقات الصرف/النحو  
- نفس محرك التحليل لاحقًا للحديث/التراث دون كسر قيد «القرآن أولًا» للطبقات العميقة  
- أكبر «ذاكرة أخطاء عربية» مفتوحة المصدر قابلة للتدقيق  

## 4) معمارية سحابية مستهدفة

```text
[واجهة /lughawi]
        │
[بوابة عربیا Contabo]
  ├─ محرك محلي (قواعد + تعلّم)
  ├─ Auto Gateway (مزودون متعددون)
  ├─ حصة مشروع مدقق العربية
  └─ مفاتيح مستخدم مشفّرة
        │
[ذاكرة]
  ├─ .data/ (تشغيل)
  └─ data/lughawi/ (Git)
```

## 5) معايير «أكبر مشروع لغوي تقني عربي»

- تغطية أخطاء الواقع اليومي (جمهور) لا المختبر فقط  
- شرح يُعلّم لا يستبدل فقط  
- استدامة مجانية عبر Auto + مفاتيح شخصية  
- عدم المساس بنص الوحي  
- قابلية التوسع إلى صوت/فيديو دون إعادة بناء الهوية
