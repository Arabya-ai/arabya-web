# دليل المالك — عربية ستوديو داخل عربية

آخر تحديث: 2026-07-31

## الوصول

- القائمة: **خدماتنا → الاستوديو**، أو رابط **الاستوديو** في الفوتر
- قائمة الحساب (بعد الدخول): **الاستوديو** لكل المستخدمين
- المسار المباشر: `/studio`
- محرر خفيف (صورة/فيديو سريع): `/create` · `/create/image` · `/create/video`
- فيديو ذكي (موضوع + ذكاء اصطناعي، محرك منفصل): `/studio/ai` — الدليل: `docs/platform/mpt-studio-owner-guide-ar.md`

## ماذا ترى

واجهة **عربية ستوديو** تحت `/studio`: هبوط، مشاريع، محرر، تصدير. طابور الجودة والمصادر للمحررين/الأدمن عبر `/studio/queue` و`/studio/sources`.

## خطوات سريعة

1. سجّل الدخول (المالك بلس تلقائيًا عبر البريد المضمّن أو `ARABYA_PLUS_EMAILS`).
2. افتح **الاستوديو** من الهيدر/الفوتر أو `/studio`.
3. مشروع جديد → المحرر → تصدير MP4 (بلس، Chrome/Edge، ≤ 40 آية) أو PNG.
4. خلفيات Pexels / Pixabay:
   - على السيرفر (`.env.production.local`): `PEXELS_API_KEY` و/أو `PIXABAY_API_KEY` (مفتاح أو عدة مفصولة بفاصلة)
   - و/أو `PEXELS_API_KEYS` / `PIXABAY_API_KEYS`
   - و/أو مفتاح في `/studio/settings` (كل خدمة بمفتاحها المنفصل)
   عند 401/403/429 يجرّب الخادم المفتاح التالي تلقائيًا.

الصوت عبر `/api/create/audio` والخلفيات عبر `/api/studio/pexels` و`/api/studio/pixabay` (يتطلبان تسجيل الدخول).

`/create` مركز إنشاء خفيف منفصل عن `/studio` (لا يُعاد توجيهه). الاستوديو الكامل يبقى تحت `/studio`.

## حدود معروفة (ليست أعطالًا)

- معاينة المحرر تعرض **نص الآيات الحقيقي** من مصحف عربية (مع تنقّل بين الآيات ومزامنة أثناء تشغيل الصوت).
- مفاتيح الترجمة/التفسير في الواجهة محفوظة للتفعيل لاحقًا في ملف الفيديو.
- Safari قد لا يدعم تصدير WebCodecs — استخدم Chrome أو Edge.

دليل الاستخدام الشامل: `docs/platform/owner-how-to-use-ar.md`
