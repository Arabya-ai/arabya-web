## تغيير مهم للمالك (بدون ملفات ولا أوامر)

من **مراقبة النظام** في حساب السوبر أدمن (`/admin/ops`):

1. تبويب **المفاتيح** — الصق مفتاحًا أو دفعة مفاتيح → تُحفظ مشفّرة على السيرفر.  
2. تعمل لكل المشتركين المجانيين حتى **1500 كلمة/شهر**.  
3. بعدها يطلب النظام من المستخدم مفتاحه الخاص من إعدادات لغوي.  
4. تبويب **تقارير الاستخدام** — أعلى المستهلكين وصحة كل مفتاح.

لا حاجة لتعديل `.env` لإضافة المفاتيح بعد الآن.

## أوامر الدمج والنشر

انظر `OWNER-DEPLOY-MERGE-AR.md` و `OWNER-PROVIDERS-SETUP-AR.md`.

```bash
cd /var/www/arabya-web && git fetch origin main && git checkout main && git pull --ff-only origin main && bash scripts/contabo-deploy.sh
```

## مطلوب منك الآن

1. ادمج PR هذه الدفعة على GitHub.  
2. انشر على Contabo بالأمر أعلاه.  
3. افتح `/lughawi` وجرّب الواجهة الجديدة، و`/admin/ops` إن كنت سوبر أدمن.  
4. **خطوة المفاتيح التالية فقط**: أنشئ 3 مفاتيح Google من 3 جيميلات حسب `OWNER-PROVIDERS-SETUP-AR.md` والصقها في `.env` أو أرسلها للوكيل.
