# دليل المالك — آيات ستوديو داخل عربية

آخر تحديث: 2026-07-26

## الوصول

- القائمة: **خدماتنا → الاستوديو**، أو رابط **الاستوديو** في الفوتر
- قائمة الحساب (بعد الدخول): **الاستوديو** لكل المستخدمين
- المسار المباشر: `/studio`

## ماذا ترى

واجهة **آيات ستوديو** (Lovable) تحت `/studio`: هبوط، مشاريع، محرر، تصدير. طابور الجودة والمصادر للمحررين/الأدمن عبر `/studio/queue` و`/studio/sources`.

## خطوات سريعة

1. سجّل الدخول (المالك بلس تلقائيًا).
2. افتح **الاستوديو** من الهيدر/الفوتر أو `/studio`.
3. مشروع جديد → المحرر → تصدير MP4 (بلس، Chrome/Edge).
4. اختياري: Pexels في `/studio/settings`.

`/create` يحوّل تلقائيًا إلى `/studio`.
