# خطوات المالك — مفاتيح لغوي (بدون تعقيد تقني)

هدف هذه الصفحة: تفعيل **الحصة المجانية** و**وضع Auto** بأمان.

> لا ترسل المفاتيح في شات عام إن أمكن. الأفضل وضعها مباشرة على سيرفر Contabo.  
> إن احتجت مساعدتي: أرسل المفاتيح في رسالة خاصة داخل Cursor Cloud فقط، ثم احذفها من الشات بعد التفعيل.

---

## أ) ماذا تحتاج؟

| النوع | لمن؟ | ماذا يفعل؟ |
|------|------|------------|
| مفاتيح **مشروع عربية** | أنت (المالك) | تمول الحصة المجانية 15000 حرف/شهر لكل مستخدم مسجّل |
| مفتاح **المستخدم** | كل زائر يريد أكثر من الحصة | يعمل على حسابه وحده |

---

## ب) من أين أحصل على مفاتيح مجانية/رخيصة؟

نفّذ بالترتيب (الأسهل أولًا):

### 1) Groq (موصى به للبداية)
1. افتح: https://console.groq.com  
2. سجّل بحساب Google/GitHub  
3. من API Keys → Create API Key  
4. انسخ المفتاح (يبدأ غالبًا بـ `gsk_`)

### 2) Google AI Studio (Gemini)
1. افتح: https://aistudio.google.com/apikey  
2. Create API key  
3. انسخ المفتاح

### 3) OpenRouter
1. افتح: https://openrouter.ai/keys  
2. Create key  
3. انسخ المفتاح

### 4) OpenAI / Anthropic (اختياري مدفوع)
- https://platform.openai.com/api-keys  
- https://console.anthropic.com

## ج) أين أضع مفاتيح المشروع؟ (Contabo)

1. ادخل السيرفر عبر SSH أو Terminal في اللوحة (لينكس، ليس PowerShell ويندوز).  
2. افتح ملف البيئة الخاص بالموقع (غالبًا `.env` أو `.env.production` داخل `/var/www/arabya-web`).  
3. أضف أحد الخيارين:

**خيار سهل — مجمّع Auto واحد:**

```bash
LUGHAWI_MONTHLY_QUOTA_CHARS=15000
LUGHAWI_PROJECT_AI_POOL=groq:ضع_مفتاح_groq|google:ضع_مفتاح_google
```

**أو مفاتيح منفصلة:**

```bash
LUGHAWI_MONTHLY_QUOTA_CHARS=15000
LUGHAWI_GROQ_API_KEY=gsk_...
LUGHAWI_GOOGLE_API_KEY=AIza...
```

4. احفظ الملف.  
5. أعد تشغيل التطبيق:

```bash
cd /var/www/arabya-web
bash scripts/contabo-deploy.sh
```

أو إن كان التطبيق يعمل أصلًا:

```bash
pm2 restart arabya-web --update-env
```

## د) ماذا أرسل لك إن أردت أن أضبطها أنا؟

أرسل في رسالة خاصة داخل Cursor بهذا الشكل فقط (بدون شرح زائد):

```text
GROQ=gsk_...
GOOGLE=AIza...
OPENROUTER=sk-or-...
```

ثم بعد التأكيد احذف الرسالة إن أحببت.  
لن أضع المفاتيح في Git أبدًا.

---

## هـ) كيف يتأكد المستخدم أن مفتاحه آمن؟

1. يسجّل الدخول في عربية.  
2. يفتح `/lughawi` → الإعدادات.  
3. يختار المزود ويلصق مفتاحه ويحفظ.  
4. يظهر فقط `••••` + آخر 4 أحرف.  
5. لا أحد غير صاحب الحساب يستطيع استخدامه.

## و) ماذا يفعل وضع Auto؟

مثل Cursor: إن رفض Groq الطلب أو امتلأ الرصيد، يجرّب Google ثم OpenRouter ثم الباقي تلقائيًا — بدون أن يختار المستخدم يدويًا في كل مرة.
