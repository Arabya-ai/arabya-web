# جعل مستودع GitHub خاصاً (Private)

## لماذا؟

مستودع **Public** يسمح لأي شخص بنسخ **كل الكود** وملفات `/data` دفعة واحدة — أخطر من تقليد واجهة الموقع من الرابط فقط.

## الحالة (آخر فحص)

- المستودع: `Arabya-ai/arabya-web`
- كان: **Public**
- وكيل السحابة **لا يملك صلاحية** تغيير الرؤية (403) — يجب على **مالك المنظمة** تنفيذ الخطوات يدوياً.

## مطلوب من المالك (دقيقتان)

1. افتح: https://github.com/Arabya-ai/arabya-web/settings  
2. انزل إلى **Danger Zone**  
3. **Change repository visibility** → **Make private**  
4. أكّد اسم المستودع  
5. (اختياري) في **Settings → Actions** تأكد أن CI ما زال يعمل للفريق

## بعد التخصيص

- الزوار ما زالوا يرون الموقع على `arabya.org` — التخصيص يخص **الكود على GitHub** فقط.
- المتعاونون يحتاجون دعوة إلى المنظمة أو المستودع.
- لا تشارك رابط «raw» لملفات `/data` علناً.
