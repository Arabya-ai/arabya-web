# Arabya brand lock for Taste / redesign skills

When applying `redesign-existing-projects` or soft visual skills to this repo:

## Must keep
- CSS tokens from `src/app/globals.css`: `--brand`, `--brand-deep`, `--brand-soft`, `--surface`, `--ink`, `--bg`
- Arabic-first RTL; fonts Cairo / IBM Plex Arabic / Reem Kufi / UthmanicHafs
- Calm professional panels — not noisy SaaS dashboards

## Banned (even if a skill suggests them)
- Purple / indigo AI gradients
- Warm cream + terracotta “AI default” editorial look
- Inter / Roboto / Geist as primary Arabic UI fonts
- Rewriting `/mushaf/*` reading canvas or `WordStudyDock` study layers
- Three equal marketing feature cards in the home hero
- Heavy GSAP / magnetic cursors unless explicitly requested

## Preferred dials
- VARIANCE: low–medium (asymmetric only where it helps hierarchy)
- MOTION: low (hover + 2–3 subtle entrance transitions)
- DENSITY: medium on dashboards, lower on home title block
