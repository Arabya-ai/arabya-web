# التسميع الذكي على Contabo (مجاني — بلا مفاتيح)

## ماذا أُضيف؟
- مسار `/tahfeez` للمسجّلين فقط
- بورتفوليو في `/account/tahfeez`
- متابعة السوبر أدمن في `/admin/tahfeez` + ترقية الأدوار من `/admin/users`

## التعرف على الصوت
الإصدار الحالي يستخدم **التعرف على الكلام في المتصفح** (Chrome/Edge) مجاناً بدون أي مفتاح API، ثم يطابق الكلمات على السيرفر.

لاحقاً يمكن تشغيل نموذج قرآن محلي (whisper.cpp) على نفس السيرفر لتحسين الدقة — بلا اشتراكات.

## بعد السحب
```bash
cd /var/www/arabya-web
git pull
bash scripts/contabo-deploy.sh
```

تأكد أن `ARABYA_USER_SYNC_ENABLED=1` حتى تُحفظ بورتفوليوهات التسميع في SQLite.
