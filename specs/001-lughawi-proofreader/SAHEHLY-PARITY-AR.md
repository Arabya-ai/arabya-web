# مطابقة صحح لي → لغوي (هوية عربية)

| صحح لي | لغوي |
|--------|------|
| صحّح الآن | المحرر / صحّح الآن |
| المساعد القرآني | المساعد القرآني (بحث آيات + نسخ) |
| تفقيط الأرقام | تفقيط (موجود + وحدة قائمة) |
| الترجمة | الترجمة |
| التعرف الضوئي OCR | OCR (واجهة جاهزة · المحرك لاحقًا) |
| إضافة كروم | قريبًا |
| الملف / إحصائيات / اشتراكات | عبر حساب عربية + حصة لغوي |
| ترقية | مؤجّل (بعد ثبات أ→د) |

## تدقيق
- وضعان: إملائي+نحوي / إملائي فقط
- عداد أحرف + حد أقصى للطلب
- زر «ابدأ التصحيح»

## حصة مجانية
- صحح لي: ~1500 حرف/يوم في اللقطات
- لغوي: **1500 كلمة/شهر** على مفاتيح المدير، ثم BYOK

لا ننسخ ألوان/شعار صحح لي — هوية عربية تيل.
