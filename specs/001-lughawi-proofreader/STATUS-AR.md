## تغيير مهم للمالك (بدون ملفات ولا أوامر)

من **مراقبة النظام** (`/admin/ops`):

1. تبويب **المفاتيح** — الصق مفتاحًا أو دفعة → تُحفظ مشفّرة.  
2. تعمل للمشتركين المجانيين حتى **1500 كلمة/شهر**.  
3. بعدها يطلب النظام مفتاح المستخدم من إعدادات لغوي.  
4. تبويب **تقارير الاستخدام** — أعلى المستهلكين + تنبيهات المفاتيح الضعيفة.

لا حاجة لتعديل `.env` لإضافة المفاتيح اليومية.

## مطلوب منك الآن

1. ادمج PR هذه الدفعة على GitHub.  
2. انشر على Contabo:

```bash
cd /var/www/arabya-web && git fetch origin main && git checkout main && git pull --ff-only origin main && bash scripts/contabo-deploy.sh
```

3. افتح `/admin/ops` → تبويب **المفاتيح** → الصق أول مفتاح Google (Create API key من aistudio.google.com).  
4. افتح `/lughawi` وجرّب التصحيح ودرجة الجودة.
