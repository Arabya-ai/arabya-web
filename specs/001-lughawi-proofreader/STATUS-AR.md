# لغوي — تقرير الحالة والخارطة (أغسطس 2026)

**المنتج**: لغوي (ركيزة التدقيق اللغوي داخل عربية)  
**المحرك**: `lughawi-engine@1.1.0` (متعدد المراحل)  
**النشر**: Contabo + PM2 · `https://www.arabya.org/lughawi`

---

## 1) الحالة الحالية (بعد مراجعة هذا الإصدار)

### ما يعمل الآن في الإنتاج/المستودع

| الطبقة | الحالة | ملاحظات |
|--------|--------|---------|
| واجهة `/lughawi` | جاهزة | محرر ثنائي اللوحة، شريط أدوات لاصق، أمثلة، اختصار Ctrl+Enter |
| تدقيق أوفلاين | جاهز | إملاء + نحو + أسلوب + ترقيم + حماية قرآن |
| تعلّم قبول/رفض | جاهز | يغذي `.data` ثم يُرقَّى إلى Git |
| إعادة صياغة / ترجمة / تشكيل AI | جاهز تقنيًا | يحتاج مفاتيح مشروع أو BYOK |
| وضع Auto (failover) | جاهز | مفاتيح مستخدم ثم مجمّع المشروع |
| تفقيط أرقام | جاهز | محلي |
| صوت / فيديو | غير مبني | مخطّط في الرؤية |

### معمارية المحرك (مثل محركات الاستدلال)

```text
النص
  → حماية القرآن (guard)
  → مرحلة إملاء/معجم (spelling + learned)
  → مرحلة نحو واتفاق (grammar)
  → مرحلة أسلوب/تنسيق (style)
  → مرحلة ترقيم (punctuation)
  → دمج التعارضات (merge: الأسبق يفوز)
  → ترتيب الثقة (rank)
  → مخرجات + أثر المراحل (trace)
```

هذا نفس منطق بناء محركات NLP/AI: **مراحل مسجّلة · أثر قياس · دمج تعارض · عتبة ثقة** — قابل لاحقًا لاستبدال أي مرحلة بنموذج GEC أو نموذج عربي مفتوح دون كسر عقد `LughawiEdit`.

### تجربة المستخدم (تلميع هذا الإصدار)

- شريط حالة يعرض إصدار المحرك وجاهزية Auto  
- أمثلة جاهزة للتجربة الفورية  
- تمييز أنواع الاقتراح (إملاء/نحو/ترقيم/أسلوب) ونسبة الثقة  
- مزامنة تمرير بين التمييز والقائمة  
- هيكل عظمي أثناء المعالجة · نسخ مع تأكيد · تراجع · مسح  
- أثر مراحل المحرك قابل للفتح (للشفافية التقنية)  
- تنقّل محلي يوضح الصفحة الحالية · حركات خفيفة مع احترام `prefers-reduced-motion`

## 2) فجوات معروفة (صادقة)

1. **النحو ليس محلّلًا كاملًا** — قواعد واستدلالات؛ ليس إعرابًا عميقًا بعد.  
2. **لا نموذج GEC مدمج محليًا على Contabo** بعد (CAMeL / نموذج عربي مفتوح).  
3. **مفاتيح مشروع Auto** قد تكون فارغة على السيرفر حتى يضيفها المالك.  
4. **لا تدقيق DOCX/PDF** ولا إضافة متصفح بعد.  
5. **لا مسار صوت→نص→تدقيق** ولا عناوين فيديو بعد.  
6. **دقائق GitHub Actions** مستنفدة مؤقتًا — النشر اليدوي عبر PuTTY يعمل.

## 3) الخطوات القادمة بالتفصيل (لتصبح المرجع العالمي)

### المرحلة أ — تعميق المحرك النصي (الأساس العالمي)

1. توسيع قاموس الأخطاء الواقعية من تغذية الجمهور + قوائم مفتوحة (BAYAN وغيرها).  
2. إضافة مرحلة **صرف خفيفة** (جمع/مفرد شائع، أوزان خاطئة متكررة).  
3. دمج **نموذج GEC عربي** كمرحلة اختيارية على Contabo (Docker sidecar) بنفس عقد التعديلات.  
4. لوحة ثقة وتصفية (إظهار عالي الثقة فقط / الكل).  
5. قاموس مؤسسي «لا تصحّح هذه الكلمات» لكل حساب/فريق.

### المرحلة ب — منصة الاستخدام الكثيف

1. استيراد ملفات DOCX/PDF/Markdown.  
2. API عام للمواقع والمحررات (مع مفتاح مشروع).  
3. إضافة متصفح + اختصار سطح مكتب.  
4. مقارنة نسختين (قبل/بعد) وتصدير تقرير تصحيحات.

### المرحلة ج — الوسائط (نص ← صوت ← صورة)

1. تفريغ صوت (Whisper/faster-whisper على Contabo) → لغوي → نص مصحح.  
2. تدقيق ترجمة الشاشة / SRT / عناوين الاستوديو.  
3. ربط استوديو عربية: سكربت فصيح قبل التسجيل.  
4. كشف لهجة → اقتراح فصحى (اختياري، بعد ثبات الفصحى).

### المرحلة د — الريادة والثقة

1. معيار تقييم عربي داخلي (مجموعة اختبار ذهبية + لوحة جودة أسبوعية).  
2. شفافية المصادر والقواعد (موسوعة أخطاء لغوي).  
3. عدم المساس بنص الوحي دائمًا.  
4. واجهة ومحتوى تعليمي يجعل القبول/الرفض درسًا لا زرًا فقط.

## 4) مطلوب من المالك الآن

1. فتح [https://www.arabya.org/lughawi](https://www.arabya.org/lughawi) وتجربة الأمثلة الثلاثة وقبول/رفض اقتراح.  
2. (اختياري للسحابة) إضافة مفتاح Groq أو غيره في `.env` على Contabo ثم `pm2 restart arabya-web --update-env` — الدليل: `OWNER-KEYS-AR.md`.  
3. بعد دمج هذا الفرع: نشر Contabo كالعادة عبر سكربت النشر في PuTTY.
