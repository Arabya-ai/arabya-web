# دليل استخدام مركز الإنشاء والخطط

آخر تحديث: 2026-07-26

## للمالك / المشترك

### 1) الخطط

| الخطة | من يحصل عليها؟ | ماذا يفعل؟ |
|--------|----------------|------------|
| **Free** | أي حساب Google بعد الدخول | PNG مربع بعلامة «عربية» |
| **Plus** | المالك (`egywebdev@gmail.com`, `arabyaaicom@gmail.com`)، أو `ARABYA_PLUS_EMAILS`، أو محرر/مدير | مقاسات اجتماعية بدون علامة، لون خلفية، فيديو MP4 |

قراءة المصحف ودراسة الكلمة **مجانية للضيف** — لا تحتاج حسابًا.

### 2) مسارات الاستخدام

1. سجّل الدخول من `/login`.
2. افتح `/create` أو من القائمة «خدماتنا» → إنشاء / الخطط.
3. **صورة:** `/create/image?s=1&v=1` — اختر السورة والآية → تنزيل PNG.
4. **فيديو (بلس):** `/create/video` — نطاق آيات (حد أقصى 20) + قارئ → تنزيل MP4 على **Chrome أو Edge**.
5. من صفحة إعراب آية أو لوحة دراسة الكلمة: أزرار «إنشاء صورة / فيديو».

### 3) التسعير

- `/pricing` — مقارنة Free/Plus.
- **PayPal:** غير مفعّل بعد؛ سيُربط لاحقًا. حتى ذلك الحين Plus يدوي.

### 4) متغيرات Vercel (موصى بها)

```
ARABYA_PLUS_EMAILS=egywebdev@gmail.com,arabyaaicom@gmail.com
```

(البريدان مضمّنان أصلًا في الكود عبر `OWNER_PLUS_EMAILS`.)

## للمطوّر

- خطط: `src/lib/plans.ts`
- PNG: `src/lib/create-ayah-image.ts` + `/api/create/image`
- فيديو: `src/lib/media-export/` + `/api/create/ayahs`
- لا تلمس `/api/og` عند تعديل صور الإنشاء — مسار منفصل عمدًا.
