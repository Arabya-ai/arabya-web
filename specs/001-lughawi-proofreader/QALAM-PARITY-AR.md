# مطابقة واجهات قلم → لغوي (هوية عربية)

**التاريخ**: 2026-08-20  
**المصدر**: لقطات حساب مجاني في قلم (Qalam) أرسلها المالك  
**المبدأ**: نستلهم **الوظائف وتدفق التجربة**، لا ننسخ الشعار ولا الألوان الحرفية ولا النصوص التسويقية. هوية عربية (تيل `--brand`) أولاً.

---

## ماذا رأينا في قلم (ملخص العناصر)

### تخطيط عام (3 أعمدة)
| المنطقة | المحتوى |
|---------|---------|
| شريط علوي | شعار · اشترك · ملف مستخدم |
| يمين | تنقل الوحدات: مستندات، ترجمة، ملحقات، اقتباسات، أسلوب، معجم، نماذج، إعدادات |
| وسط | محرر غني + شريط أدوات عربي |
| يسار | تصفية أنواع الأخطاء + «تصحيح جميع الأخطاء» + عدد كلمات + شارة عدد الأخطاء |

### ألوان الأخطاء (لغة بصرية ثابتة)
| النوع | اللون في قلم | في لغوي الآن |
|-------|--------------|--------------|
| إملاء | أحمر | `--lughawi-spell` أحمر |
| نحو | أزرق | `--lughawi-grammar` أزرق |
| صياغة/أسلوب | أصفر/برتقالي | `--lughawi-style` كهرماني |
| معجم/صرف | بنفسجي | `--lughawi-morph` بنفسجي |
| ترقيم | رمادي | `--lughawi-punct` رمادي |
| أخرى | سماوي خفيف | `--lughawi-other` |

### شريط الأدوات العربي
- إعادة صياغة ✅ (موجود)
- تدقيق الآيات ✅ (زر جديد + حماية قرآن)
- تشكيل ✅ / إزالة التشكيل ✅
- تفقيط ✅
- ترجمة ✅
- تنسيق غني (غامق/مائل…) 🔜 لاحقًا عند مستندات غنية

### وحدات جانبية
| وحدة قلم | حالة لغوي |
|----------|-----------|
| المستندات | هيكل قائمة · محتوى قريبًا |
| الترجمة | مربوطة بأداة الترجمة الحالية |
| الملحقات | قريبًا |
| كاشف الاقتباسات | قريبًا |
| ضبط الأسلوب | قريبًا (لوحة إعدادات قواعد) |
| إدارة المعجم | قريبًا |
| إدارة النماذج | قريبًا |
| الإعدادات | مفاتيح AI + حصة |

### قائمة المستندات / OCR / تصدير PDF·DOCX
🔜 مرحلة ب (الاستخدام الكثيف)

---

## ما طُبّق في هذه الدفعة
- هيكل قشري بثلاثة أعمدة بهوية عربية
- فلاتر ألوان قابلة للتبديل
- شارة عدد الأخطاء + عدد الكلمات
- أزرار تدقيق آيات وإزالة تشكيل
- لوحة سوبر أدمن `/admin/ops` لرصد الأدوات والمفاتيح

## ما ينتظر لقطات «صحح لي»
بعد إرسال واجهات صحح لي نضيف صف مقارنة ثانٍ ونضبط أي فجوات UX إضافية.
