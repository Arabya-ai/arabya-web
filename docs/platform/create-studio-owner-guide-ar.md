# دليل المالك — عربية ستوديو داخل عربية

آخر تحديث: 2026-07-26

## الوصول

- القائمة: **خدماتنا → الاستوديو**، أو رابط **الاستوديو** في الفوتر
- قائمة الحساب (بعد الدخول): **الاستوديو** لكل المستخدمين
- المسار المباشر: `/studio`

## ماذا ترى

واجهة **عربية ستوديو** تحت `/studio`: هبوط، مشاريع، محرر، تصدير. طابور الجودة والمصادر للمحررين/الأدمن عبر `/studio/queue` و`/studio/sources`.

## خطوات سريعة

1. سجّل الدخول (المالك بلس تلقائيًا عبر البريد المضمّن أو `ARABYA_PLUS_EMAILS`).
2. افتح **الاستوديو** من الهيدر/الفوتر أو `/studio`.
3. مشروع جديد → المحرر → تصدير MP4 (بلس، Chrome/Edge، ≤ 40 آية) أو PNG.
4. خلفيات Pexels:
   - على Vercel: `PEXELS_API_KEY` = مفتاح أو عدة مفصولة بفاصلة (يكفي وحده)
   - و/أو `PEXELS_API_KEYS`
   - و/أو مفتاح في `/studio/settings`
   عند 401/403/429 يجرّب الخادم المفتاح التالي تلقائيًا.

الصوت عبر `/api/create/audio` والخلفيات عبر `/api/studio/pexels` (يتطلبان تسجيل الدخول).

`/create` يحوّل تلقائيًا إلى `/studio`.

## حدود معروفة (ليست أعطالًا)

- معاينة المحرر تقريبية للنص؛ الخلفية من Pexels تُحمَّل عبر وسيط عربية (`/api/studio/media`).
- مفاتيح الترجمة/التفسير في الواجهة محفوظة للتفعيل لاحقًا في ملف الفيديو.
- Safari قد لا يدعم تصدير WebCodecs — استخدم Chrome أو Edge.
