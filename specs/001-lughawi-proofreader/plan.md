# Implementation Plan: لغوي — محرك التدقيق اللغوي العربي

**Branch**: `cursor/lughawi-arabic-proofreader-51a7` | **Date**: 2026-08-20 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/001-lughawi-proofreader/spec.md`

## Summary

بناء محرك **لغوي**: خط أنابيب هجين (قواعد + أدوات مفتوحة + نماذج GEC + طبقة مزودي AI اختيارية) داخل عربیا، مع واجهة `/lughawi`، ظهور في **خدماتنا**، حصة شهرية من مشروع «مدقق العربية»، ومفاتيح المستخدم (BYOK) لعدة مزودين. التميّز: شرح القواعد، حماية النص القرآني، وربط اختياري بتحليل الكلمة في عربیا.

## Technical Context

**Language/Version**: TypeScript (Next.js 15 App Router) + Python 3.11+ لمحرك NLP المنفصل  
**Primary Dependencies**: Next.js/React الحالي؛ خدمة `services/lughawi-engine` (FastAPI أو مشابه)؛ CAMeL Tools / نماذج Hugging Face GEC؛ عميل موحّد لمزودي AI  
**Storage**: SQLite على Contabo لحسابات/مفاتيح مشفّرة/حصص (عند `ARABYA_USER_SYNC_ENABLED=1`)؛ لا تخزين دائم لنصوص المستخدم افتراضيًا  
**Testing**: Vitest للعقود والوحدات في Next؛ اختبارات Python لمراحل المحرك؛ عيّنة ذهبية عربية للتدقيق  
**Target Platform**: محلي `localhost:3000` + Contabo (`arabya.org`)؛ محرك NLP كعملية جانبية على نفس الخادم أو حاوية  
**Project Type**: web-app + sidecar NLP service  
**Performance Goals**: فقرة ≤500 حرف: استجابة تدقيق محلي يشعر بها المستخدم خلال ~3 ثوانٍ على الجهاز النموذجي؛ مسار AI حسب المزود  
**Constraints**: عدم كسر المصحف/التلاوة؛ عدم تسريب مفاتيح؛ ضيف بدون إجبار حساب للمسار المحلي؛ حدود معدل للحصة  
**Scale/Scope**: إطلاق تدريجي (P1 محلي+واجهة+حصة/BYOK هيكليًا → P2 نحو/صياغة/تشكيل → P3 تفقيط/API عام/امتداد متصفح)

## Architecture — كيف يُصنع محرك مثل صححلي

صححلي (صخر) يجمع: **محلل صرفي/معجمي + قواعد + إحصاء/تعلم آلة + تشكيل متعدد الأوضاع + طبقة منتجات**.  
لغوي يحاكي نفس الطبقات بمكوّنات مفتوحة + AI اختياري:

```text
                    ┌─────────────────────────────────────┐
                    │  واجهة عربیا  /lughawi (RTL)         │
                    │  قبول/رفض · ملاحظات · حصة · BYOK    │
                    └──────────────┬──────────────────────┘
                                   │ HTTPS
                    ┌──────────────▼──────────────────────┐
                    │  Next.js API  /api/lughawi/*         │
                    │  مصادقة · حصة · تشفير مفاتيح · حد معدل │
                    └──────┬───────────────┬──────────────┘
                           │               │
              ┌────────────▼──────┐   ┌────▼─────────────────┐
              │ lughawi-engine    │   │ AI Gateway موحّد      │
              │ (محلي، مجاني)     │   │ OpenAI/Anthropic/…   │
              │                   │   │ مفتاح مستخدم أو مشروع │
              │ 1) تطبيع          │   └──────────┬───────────┘
              │ 2) حماية قرآن     │              │
              │ 3) قواعد إملاء    │   شرح معمق / إعادة صياغة /
              │ 4) صرف CAMeL      │   تدقيق سياقي عند الطلب
              │ 5) GEC مفتوح      │
              │ 6) ترقيم          │
              │ 7) تشكيل مفتوح    │
              │ 8) دمج تعديلات    │
              │    بلا تعارض      │
              └───────────────────┘
```

### طبقات المحرك (مقابلة صححلي)

| طبقة صححلي | طبقة لغوي | مصدر |
|------------|-----------|------|
| Spell Check | قواعد إملاء + قاموس/مسافة تحرير | قواعد عربية مخصصة + مفتوح |
| Morphological & Lexical Analyzer | تحليل صرفي | CAMeL Tools |
| Grammar / AI | كشف وتصحيح نحوي | CAMeL Arabic GEC (+ AI اختياري) |
| Rule explanations | Rule Note لكل Edit | ARETA-like types + قوالب عربية |
| Tashkeel modes | تشكيل كامل/جزئي/أواخر/إلزامي | نماذج تشكيل مفتوحة + صقل قواعد |
| Smart rewrite | إعادة صياغة | AI Gateway (حصة أو BYOK) |
| Quran assistant | حماية + روابط مصحف/دراسة | `/data` + مسارات عربیا |

### مسار استهلاك AI (حصة + BYOK)

```text
طلب ميزة AI؟
  لا → المحرك المحلي فقط
  نعم →
    هل للمستخدم حصة مشروع متبقية؟
      نعم → استخدم مفتاح مشروع «مدقق العربية» · خصم الحصة
      لا  → هل يوجد مفتاح مستخدم للمزود المختار؟
            نعم → BYOK
            لا  → ارفض الميزة AI بلطف · أبقِ المحلي
```

## Phased delivery

| مرحلة | ماذا يُسلَّم | يعتمد على |
|-------|-------------|-----------|
| **A — الهيكل** | مواصفة + خطة + عقود (هذا المجلد) | موافقة المالك على الحصة الافتراضية |
| **B — محرك أولي** | `lughawi-engine` قواعد إملاء + تطبيع + حماية قرآن بسيطة + عقد `/v1/proofread` | لا مفاتيح AI |
| **C — واجهة** | `/lughawi` + رابط خدماتنا + قبول/رفض + ملاحظات | B |
| **D — حصة وBYOK** | تخزين مفاتيح مشفّر + عدّاد شهري + بوابة مزودين | حسابات Contabo |
| **E — GEC وتشكيل** | دمج نماذج مفتوحة + أوضاع تشكيل | موارد خادم كافية |
| **F — صياغة وتميّز** | إعادة صياغة · تحليل كلمة · صفحة خدمات عربية | D |
| **G — احترافي لاحق** | تفقيط · API عام محدود · امتداد متصفح | استقرار E/F |

## Complexity Tracking

| قرار | لماذا ليس أبسط | البديل المرفوض |
|------|----------------|----------------|
| خدمة Python منفصلة | نماذج CAMeL/HF ثقيلة على عملية Next | تشغيل كل شيء داخل Serverless Next — غير مناسب Contabo الطويل |
| بوابة AI موحّدة | تعدد مزودين + BYOK + حصة | استدعاء مباشر من المتصفح لمفتاح المستخدم — يسرب المفتاح |
| خط أنابيب مراحل | منع تعارض التعديلات (مثل BAYAN) | نموذج واحد يكتب النص كله بدون مواضع — يضعف الشرح والقبول الجزئي |
